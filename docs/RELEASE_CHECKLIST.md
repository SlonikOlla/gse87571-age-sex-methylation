# GitHub and Zenodo release checklist

1. Create a public GitHub repository and upload the contents of this package (not the enclosing ZIP folder).
2. Confirm that no participant-level source matrices, credentials, or local paths were added.
3. Create release `v1.0.0` and tag the exact version supporting the submitted manuscript.
4. Connect the repository to Zenodo and archive the release.
5. Add the GitHub URL and Zenodo DOI to the manuscript Data and Code Availability section.
6. Update `CITATION.cff` with the manuscript DOI and repository URL when available.
7. Keep the archived release unchanged; make later corrections in a new numbered release.
